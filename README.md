# Data Structures Laboratory – Python Practicals

This repository contains 10 standalone Python programs for the Data Structures Laboratory practical examination.

## Programs

1. Library Book Borrowing Records
2. Linear Search and Binary Search
3. Selection Sort and Bubble Sort
4. Stack-Based Undo and Redo System
5. Queue-Based Event Processing System
6. Student Record Management Using Singly Linked List
7. Hash Table Using Chaining
8. Hash Table Using Linear Probing
9. Graph Traversal Using BFS and DFS
10. Binary Search Tree Operations

## Requirements

- Python 3.x
- No external packages are required. The programs use Python's standard library.

## Run a program

Open a terminal in this folder and run, for example:

```bash
python3 Practical_02_Linear_Binary_Search.py
```

Each practical is a separate file. Run one file at a time.
